# Task 1 — Library Book Issue and Return-Validity Tracking

This folder contains a hypothetical process analysis and design proposal. The scenario is based on the supplied description of a manual library issue process: ID-card check/scan, book issue, and a handwritten return-validity date on the book. The current workflow and all performance figures are assumptions for analysis only and are not verified facts about an actual IFHE or ICFAI library process.

## Recommended reading order

1. [report.md](report.md) — narrative assessment of the current process and proposed redesign
2. [current-workflow.mmd](current-workflow.mmd) — current-state process map
3. [proposed-workflow.mmd](proposed-workflow.mmd) — proposed workflow map
4. [evidence-log.csv](evidence-log.csv) — source assumptions and supporting notes
5. [test-cases.csv](test-cases.csv) — five synthetic test scenarios
6. [time-savings.csv](time-savings.csv) — calculation model for the estimated benefit
7. [data-model.md](data-model.md) — input fields, status flow, and control logic

No real student data, borrowing records, or private identifiers are used in this package.
