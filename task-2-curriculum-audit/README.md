# Task 2 — B.Tech CSE Curriculum Audit and Redesign

This folder contains a curriculum audit and redesign proposal based on a photographed B.Tech CSE table. The course list is transcribed from the supplied image but is not independently authenticated against the official programme regulation or admission-batch syllabus.

The key issue recorded in the draft is that the visible semester totals add to 162 credits, while the printed grand total appears to be 163. That discrepancy is flagged rather than silently corrected.
